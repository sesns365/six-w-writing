✏️ 六何法分層寫作小幫手

給 AI 一個作文題目或寫作素材，就依「六何法」七個層次，一層一層引導學生從一句話寫到一篇文章。可以選要做哪幾層、替不同學生調整提示量，產出互動網頁、可直接書寫的學習單（PDF、可編輯 Word）與教師版。Claude、ChatGPT、Gemini 都能用。

  • 7 完整寫作

安裝教學

先選你用的 AI：

不用安裝，這次對話馬上用

  1. 打開 Claude、ChatGPT 或 Gemini，開一個新對話。
  2. 把下面兩行貼進對話框送出： 
    安裝skill
https://github.com/sesns365/six-w-writing
  3. AI 回覆「已啟用」後，接著說題目，例如「六何法分層寫作，題目〈我的第一次〉，四年級」。
這只對「這一次對話」有效，開新對話要再貼一次。想每次都能用，請看其他分頁的正式安裝。
Gemini 常讀不到 GitHub 網址，讀不到時改貼： 
安裝skill
https://raw.githubusercontent.com/sesns365/six-w-writing/main/gpt-gemini/instructions.md

Claude（網頁版、桌面 App）

  1. 下載安裝檔：six-w-writing.zip（不用解壓縮）。
  2. 打開 Claude，點左下角自己的名字 →「設定」→「功能（Capabilities）」。
  3. 確認「程式碼執行與檔案建立」已開啟。
  4. 往下找到「技能（Skills）」→「上傳技能」，選剛剛下載的 zip。
  5. 看到「六何法分層寫作小幫手」並且是開啟狀態，就完成了。
  6. 開新對話，直接說「六何法分層寫作，題目是……」，技能會自動啟用。
Claude 可以直接產生互動網頁、學習單 PDF、可編輯 Word 與教師版。

ChatGPT（建立自己的 GPT）

  1. 到 gpt-gemini/instructions.md，按右上角的「複製」圖示，複製全文。
  2. 在 ChatGPT 左側點「GPT」→「建立」→ 切到「設定（Configure）」。
  3. 名稱填「六何法分層寫作小幫手」，把剛剛複製的內容貼到「指示（Instructions）」。
  4. 「知識」上傳 example-lesson.json（範例）。
  5. 按「建立」儲存，之後從左側點這個 GPT 就能用。
ChatGPT 會給你一段 lesson.json，請複製後貼到 線上製作頁，就能預覽、下載互動網頁，學習單按「列印／存 PDF」。

Gemini（技能 Skills）

  1. 下載 six-w-writing.zip 並解壓縮，會得到 six-w-writing 資料夾（名稱不要改）。
  2. 用電腦開 Gemini 網頁版（或 Mac App），點「自訂」→「技能（Skills）」→「匯入」。
  3. 選取整個 six-w-writing 資料夾。
  4. 對話中輸入 /six-w-writing，或直接說「六何法分層寫作，題目是……」。
Gemini 會給你一段 lesson.json，請貼到 線上製作頁 下載成品。不想安裝，也可以把 instructions.md 全文貼在對話開頭。

Claude Code

  1. 把 six-w-writing 資料夾放到 ~/.claude/skills/（Windows：C:\Users\你的帳號\.claude\skills\）。
  2. 需要時安裝套件：
    pip install python-docx playwright
  3. 開 Claude Code，說「六何法分層寫作，題目是……」，會自動執行 scripts/build.py 產出全部檔案。

怎麼跟 AI 說

六何法分層寫作，題目〈我的第一次〉，四年級。
小明會說不會寫，只做 1–3 層，提示多；其他同學做通用版。
這是課文（貼上），做六何法分層寫作，第 4–7 層就好，提示少，用標楷。
用這張校外教學的照片做六何法寫作學習單，二年級，要注音。
可以指定說法範例
層次「只做 1–3 層」「第 4–7 層」，沒說就全部
提示量「提示多／中／少」，或描述學生：「會說不會寫」「注意力短」
字型「芫荽」（預設）、「用標楷」、「要注音」
多個版本「小明一份、其他人一份」，每個版本各一份學習單

範例：〈小安學騎腳踏車〉
