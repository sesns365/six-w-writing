# lesson.json 撰寫說明

產出前先讀這份。完整範例見 `example-lesson.json`（〈小安學騎腳踏車〉，三個版本）。

## 最外層

| 欄位 | 必填 | 說明 |
|---|---|---|
| `title` | 是 | 題目或素材名稱，會用在檔名 |
| `mode` | 是 | `"text"`：有閱讀素材，第 1–6 層答案可以比對；`"topic"`：只有作文題目，寫自己的經驗，答案都是開放的 |
| `grade` | 否 | 年級或程度說明 |
| `material` | 否 | `{name, text:[段落…], image}`。`image` 可填圖片路徑（build 時自動內嵌）或 data URI |
| `core` | 否 | 一句話說出素材核心（text）或寫作重點（topic） |
| `goals` | 否 | 2–3 條學習目標 |
| `levels` | 是 | `"1"`～`"8"`，只寫要用到的層 |
| `versions` | 否 | 學生版本，見下方；沒寫就自動做一份「通用版」 |
| `teacher` | 否 | `{tips:[…], adjust:{學習內容, 學習歷程, 學習環境, 學習評量}}` |
| `source` | 否 | 教師版最下方的出處文字 |

## 八個層次與題型

| 層 | 名稱 | type（預設） | 內容 |
|---|---|---|---|
| 1 | 三何起步 | fields | 欄位 who／where／what，句型 `{who}在{where}{what}。` |
| 2 | 五何擴寫 | fields | 加 when／how，句型可沿用第 1 層的 key，學生前面寫的會自動帶入 |
| 3 | 六何完整 | fields | 兩層為何：why1「不高興／衝突的原因」、why2「改變的原因」 |
| 4 | 事件排序 | sort | `events` 依正確順序列 4–6 個（每個 15 字內），`connectors` 連接詞 |
| 5 | 情緒加料 | fields | event（選事件）、act 動作、think 想法、feel 感受（`bankName:"情緒詞庫"`） |
| 6 | 三段成文 | parts | `parts`：開始／經過／結果，各有 `hint`、`starter`、`model` |
| 7 | 完整寫作 | essay | `prompt` 題目、`words` 字數、`starter` 開頭、`bank` 好用詞語、`model` 範文 |
| 8 | 遷移寫作與自我檢核 | transfer | `prompt`＋連結自身經驗的欄位、句型、`checks` 檢核項目（預設四項） |

### 每一層共用欄位

- `guide`：引導語（會報讀），一句話說這層要做什麼。
- `fields`：`[{key, label, hint, ans:[…], choices:[…], bank:[…], bankName, open}]`
  - `key` 用英文，全課唯一；後面層次的句型可以重複使用前面的 key。
  - `ans`：可接受的**關鍵詞**（學生答案包含其中一個就算對），例如 `["河濱公園","公園"]`。
  - `choices`：圈選用的 3 個選項，**其中一個要包含正確答案**，另外兩個是明顯錯的干擾選項。
  - `bank`：這一格的提示詞（點一下會放進格子）。
  - `open:true`：開放題，不比對答案（第 5、8 層、topic 模式都用這個）。`ans` 仍要寫一個示範答案，給教師版用。
  - `show`：教師版要顯示的完整答案（沒寫時自動用含答案的選項或 ans 第一個）。
- `frame`：句型，用 `{key}` 代表空格。網頁會自動帶入學生寫的答案。
- `sentence:false`：不要「寫成完整句子」的書寫格。`sentenceLabel` 可改提示文字。
- `bank`／`bankName`：整層的提示詞盒。
- `model`：範例句（學生版在「範例」支持開啟時顯示，教師版用紅字顯示）。
- `lines`：學習單書寫線行數。

## 學習支持與版本

| 代碼 | 名稱 | 學生看到 |
|---|---|---|
| `choices` | 圈選 | 每格下方 3 個選項，點選或圈選 |
| `bank` | 提示詞／詞庫 | 提示詞盒、連接詞、情緒詞庫、轉折詞 |
| `frame` | 句型 | 句型框（自動帶入答案）、三段開頭、寫作材料整理、文章開頭 |
| `cards` | 事件卡 | 第 4 層點卡片排序（關掉就自己寫事件） |
| `model` | 範例 | 「看範例」 |
| `speak` | 先說再寫 | 🎤 語音輸入（Chrome／Edge） |

預設提示量：`多`＝全部；`中`＝提示詞、句型、事件卡、先說再寫；`少`＝只有先說再寫。

```json
"versions": [
  {"name": "通用版", "levels": [1,2,3,4,5,6,7,8], "support": "中", "for": "全班"},
  {"name": "小明", "levels": [1,2,3], "supports": ["choices","frame","speak"], "for": "書寫困難，先說再寫"}
]
```

- `support` 用預設（多／中／少）；要細調就改用 `supports` 陣列。
- `showMaterial:false`：這個版本的學習單不印素材（例如素材另外發）。
- 選層建議：基本句與原因表達 → 1–3 層；敘事組織與描寫 → 4–6 層；完整文章 → 7 層（＋8 遷移）。可跨層搭配。

## topic 模式（只有作文題目）

- `material` 可只放題目說明或一張照片；`core` 寫「寫作重點」。
- 第 1–3 層的欄位改成問學生自己：「何人：這件事有誰？」，全部 `open:true`，`choices` 給常見選項當靈感。
- 第 4 層 `events` 放「常見的事件順序」當事件卡（例如校外教學：出發→參觀→吃午餐→回學校），學生可改寫成自己的。
- 第 7 層 `prompt` 就是作文題目。

## 自我檢查

- `python scripts/build.py lesson.json --check` 會檢查：句型的 key 是否存在、圈選裡有沒有正確答案、版本用到的層是否存在。
- 文字一律繁體中文、全形標點；句子短、一句一件事；素材 300 字以內為宜。
