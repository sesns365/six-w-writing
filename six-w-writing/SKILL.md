# 六何法分層寫作小幫手

以「堆積木」的方式，先完成基本句，再加入時間、方法、原因與感受，一層一層引導學生完成寫作。
依據：閱讀理解策略應用與實作社群「閱讀延伸寫作策略：六何法分層寫作教材」七層次架構（改編自：https://courses.dale.nthu.edu.tw/repo/14342）。

## 七個層次（＋遷移）

| 層 | 名稱 | 教材內容 | 學習重點 |
|---|---|---|---|
| 1 | 三何起步 | 找出何人、何地、何事 | 組成清楚的基本句 |
| 2 | 五何擴寫 | 加入何時、如何 | 補充時間與動作 |
| 3 | 六何完整 | 加入「為何」的兩層原因 | 理解衝突與人物改變 |
| 4 | 事件排序 | 排列事件、運用連接詞 | 建立敘事順序 |
| 5 | 情緒加料 | 結合動作、想法與感受 | 描寫人物心情轉折 |
| 6 | 三段成文 | 整理開始、經過與結果 | 完成三段式重述 |
| 7 | 完整寫作 | 重述故事或寫成文章 | 整合所學，完成文章 |
| 8 | 遷移寫作與自我檢核 | 連結自己的生活經驗 | 用到生活中、自我檢核 |

可跨層次搭配，不必每次完成全部頁面。選層建議：基本句與原因表達 1–3 層；敘事組織與描寫 4–6 層；完整文章整合 7 層。
學習檢核四重點：內容完整、組織清楚、描寫具體、自主修訂。

## 工作流程

### 步驟 1：確認需求（缺什麼才問，一次問完）

1. **題目或素材**：一篇短文（課文、自編故事）、一個事件、一張照片，或只有作文題目。
   - 有素材 → `mode:"text"`；只有題目、要寫自己的經驗 → `mode:"topic"`。
   - 老師給的是照片或 PDF：先讀出文字，請老師確認後再做。
   - 老師沒給素材、只說主題：自編一篇 200–300 字、有「衝突→轉變」的小故事，並標明「自編示範文」。
2. **年級或程度**。
3. **要做哪幾層**：沒說就全部 1–8 層做「通用版」。
4. **字型**（沒說就用芫荽）：芫荽、標楷（教育部標準楷書優先，其次標楷體）、芫荽注音（低年級或需要注音的學生）。不用黑體，因為筆畫不符合台灣標準字體。
5. **學生的學習支持**：可以說「提示多／中／少」，或描述學生（例如「小明會說不會寫」「小華注意力短，只做前三層」），由你轉成版本。沒說就做一份「通用版（提示中）」。

老師說「直接做」就用預設，不再追問。

### 步驟 2：寫 lesson.json

先讀 `references/lesson-guide.md`（欄位說明）和 `references/example-lesson.json`（完整範例）再寫。重點：

- 第 1–3 層的 `ans` 寫**關鍵詞**，`choices` 三選一且必含正確答案。
- 第 2、3 層的句型沿用前面的 key（`{who}`、`{where}`…），學生寫過的會自動帶進來，做出「句子逐步擴充」。
- 第 3 層一定是兩層為何：①不高興／衝突的原因 ②改變的原因。
- 第 4 層 `events` 依正確順序寫 4–6 個短句；第 5 層感受欄附情緒詞庫。
- 每層都寫 `model`（範例＝教師版答案）；第 7 層 `model` 寫一篇完整範文，字數符合 `words`。
- 依學生描述建立 `versions`，每個版本寫 `for` 說明適用學生；`teacher.adjust` 寫課程調整四面向。
- 低干擾：引導語一句、提示短、一層一個任務。

### 步驟 3：產生檔案

```bash
python scripts/build.py lesson.json -o 輸出資料夾            # 芫荽
python scripts/build.py lesson.json -o 輸出資料夾 --font kai  # 標楷；注音用 --font bpmf
```

產出：
- `<題目>_互動網頁.html`：學生一層一層寫，上方積木條顯示進度；對答案、🔊 報讀（優先用曉臻語音）、🎤 語音輸入、作答紀錄；「☰ 更多」可即時調整提示量。
- `<題目>_學習單_<版本>.html／.pdf`：每個版本一份 A4 學習單。學生版只有題目和作答空間（不放學習目標、教學說明），書寫線 10mm，完整寫作用方格稿紙，學生拿到就能直接寫。
- `<題目>_教師版.html／.pdf`：所有版本的紅字參考答案＋教學說明、選層建議、課程調整四面向。
- `<題目>_學習單.docx`：Word 版（學生版＋教師版），方便老師再修改。Word 預設標楷體（每台 Windows 都有）；注音版用芫荽注音，老師電腦要先安裝。

先跑 `--check` 檢查 JSON；有錯誤就修正再產生。沒有 playwright 時會用電腦上的 Chrome／Edge 輸出 PDF；都沒有就請老師用瀏覽器列印另存 PDF。

### 步驟 4：交付前自檢

- 打開學習單 PDF 看一次：每層方框沒有被切到下一頁、字型是芫荽或標楷（不是黑體）、教師版答案正確。
- 學生版不要加說明文字；引導語一句話就好，教學說明一律放教師版。
- 對照四重點：素材有交代人物、時間、地點、事件；兩層為何合理；範文有心情與想法。
- 回覆老師時說明：做了哪些版本、各版本的層次與支持、檔案清單，並提醒「可跨層搭配，依學生表現逐步減少提示」。

## 不能執行 Python 時

無法執行程式的環境（例如 Claude 網頁版沒有程式執行、ChatGPT、Gemini）：照步驟 1–2 寫好 lesson.json，請老師打開線上製作頁 https://sesns365.github.io/six-w-writing/ ，貼上 JSON 就能預覽並下載互動網頁、學習單與教師版（列印另存 PDF）。

## 注意

- 預設不加任何 logo。
- 繁體中文、全形標點；中英數之間加半形空白。
- 不放受版權保護的課文全文到公開範例；老師自己的課文只用在老師的教材裡。
